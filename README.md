# Popup Window Tab

On the sites you save, a link that would open a new tab opens in a popup window instead. Drag any edge or corner of that window — or the brass grip inside the page — to resize it. The next window opens at the size and place you left it.

## Load it in Chrome

1. Open `chrome://extensions`
2. Turn on **Developer mode**
3. Choose **Load unpacked**
4. Select this folder

Then open a website, click the extension icon, and choose **Enable this site for popup window**.

Reload a tab once if it was already open before you installed the extension.

## Settings

- Add or remove domains
- Include subdomains
- Choose new-tab links only, or every link
- Set a starting size, or just drag a popup window

Hold Alt while clicking a link if you want Chrome to handle that click normally.
