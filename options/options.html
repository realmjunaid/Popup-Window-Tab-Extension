Popup Window Tab

On the sites you save, a link that would open a new tab opens in a popup window instead. Drag any edge or corner of that window to make it bigger or smaller.

Which clicks open a popup window

Hold Alt while clicking if you want the browser to handle that link normally.

Window size

Drag any edge or corner of the popup window, or the brass grip on the page. The next one opens at the size and place you left it.
